# A&O SaaS — alcance inicial

Esta aplicación se prepara como punto de partida independiente para la administración comercial y técnica del ecosistema A&O. El scaffold muestra únicamente ese ámbito previsto; no contiene gestión funcional de organizaciones, licencias ni servicios, y no conecta con otras aplicaciones.

La definición aprobada de producto asigna exclusivamente a A&O SaaS la administración de organizaciones/clientes, franquicias, licencias, contratos, planes, soporte, infraestructura comercial y técnica, y los usuarios y permisos globales de plataforma. El módulo de Administración de plataforma que todavía aparece en ERP conserva allí su código hasta una fase documentada de traslado; su presencia actual no cambia el límite funcional aprobado.

Tiene manifest, configuración Vite/TanStack, router, navegación, layout, Dashboard, estilos y prueba de ruta propios. Las funciones de negocio quedan para una fase de producto posterior.
